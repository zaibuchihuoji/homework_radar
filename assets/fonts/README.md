# StudySerif

`NotoSerifSC-Regular.otf` is Noto Serif SC Regular, version 2.003, from
https://github.com/notofonts/noto-cjk/tree/main/Serif/SubsetOTF/SC .
The font is unmodified. Its SIL Open Font License is in `OFL-NotoSerifSC.txt`.
Registered as `StudySerif` in Flutter. Only the optional 陶白 theme uses it,
for headings; input, body text and dense lists keep their normal sans serif.
No runtime network request is needed for the font.
