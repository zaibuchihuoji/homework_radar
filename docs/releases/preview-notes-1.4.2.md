# 作业通 1.4.2 笔记体验版

这是供体验和反馈的 Android 预览版。已有作业、课表和笔记均保存在本机；建议安装前先从旧版导出备份，并妥善保管。

- 新增独立笔记入口，支持按课程、章节整理和搜索、重点标记、回收站与历史版本。
- 支持文字、多张图片、原图上的可编辑批注和手写页，提供画笔、橡皮、撤销与缩放。
- 支持手动编写自测卡片、翻面复习、标记需要再看的卡片，以及指定时间和重复方式的复习提醒。
- 新版备份包含笔记、历史版本及附件；仍可导入旧版 JSON 备份，旧备份不会清除现有笔记。
- 首页作业列表支持左右滑动切换状态筛选，删除操作保留在长按菜单中。

## 安装说明

体验包使用与 v1.4.1 相同的发布签名，应用 ID 不变，版本代码为 14。Android 手机通常下载 `app-arm64-v8a-release.apk`；32 位设备选择 `app-armeabi-v7a-release.apk`，x86_64 模拟器选择 `app-x86_64-release.apk`；不确定架构可使用 GitHub 上的 `app-release.apk` 通用包。可尝试直接覆盖安装，安装失败时不要卸载旧版，请先确认备份。

本版不提供服务器同步、模型自动出题或 iOS 安装包。单张图片和备份文字清单各限 64 MB，备份文件限 256 MB；笔记历史不会自动清理。通知是否准时送达受系统权限和后台限制影响。

本版经过自动化数据保护、主题布局、提醒回归及 Android 构建检查；相册、触控笔、系统文件选择器和通知尚需在实际手机上体验验证。
