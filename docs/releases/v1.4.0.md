# 作业通 v1.4.0

- 新增「陶白」可选主题：暖纸色、陶土橙、中文衬线标题，页面、弹窗和桌面小组件统一适配。晴黄仍为默认主题，原有主题继续保留。
- 首页搜索、同步、添加按钮统一大小、图标尺寸和间距；状态筛选与排序支持滚动吸顶。
- 识别添加保留未完成草稿，退出或重启后可继续核对；不明确的截止时间继续等待确认。
- 同步状态展示实际新增、更新、保留等明细，以及已确认获取失败的课程。
- 新增本地恢复入口，支持手动作业回收站、历史备份和恢复前备份，恢复前可先核对内容。
- 修复课表当日清单滑动后星期和课程不更新、快速切换标签页和重复打开导入预览等交互问题。
- 加强编辑、同步、账号归档和备份对旧记录、未知字段及无法读取记录的保护；保存失败时保留已填写内容，隐藏失败可恢复界面。
- 修复旧日期编辑和相邻课程时间边界问题，保留现有提醒、识别、透明小组件和点击跳转功能。

## 安装与更新

直接覆盖安装，无需卸载旧版。App 内更新优先使用 Gitee，同版本、同架构下载失败时自动回退 GitHub；下载进度和后台下载保留。

- `app-arm64-v8a-release.apk`：大多数现代安卓手机，包括 vivo X200。
- `app-armeabi-v7a-release.apk`：使用 32 位 ARM 系统的设备。
- `app-x86_64-release.apk`：x86_64 安卓设备或模拟器。
- GitHub 另提供 `app-all-release.apk` 与 `app-release.apk` 通用包，兼容旧版 App 更新。

本次发布 Android 安装包。
