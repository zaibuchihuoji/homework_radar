# 聚焦工作台其余页面实施计划

**Goal:** 将选定第三套白底、炭黑、黄色重点设计延伸为完整应用，重做课表、日历、账号、设置及其详情与弹窗。
**Architecture:** 原有 Flutter 路由、数据服务和回调继续使用；仅默认 sunny 分支重排结构，共用设置详情改为开放分区。其他主题保留原来字体、材质和布局分支。新增轻量 UI 组件，不增加依赖。
**Spec:** 用户本轮请求与已选视觉稿 `exec-65cacbba-c7a1-4fd5-a361-c067871067a0.png`；已授权直接落地，不再重复方案审批。课表/日历具体延伸布局由本轮设计判断。

## 约束
- 不使用子代理，不提交、不发布，不开个人模拟器。
- 保护上一轮全部未提交代码。已外部备份源码和补丁。
- 不改 AppState、模型、存储键、同步/导入合并、账号登出与备份恢复语义。
- 保留全16节、所有课程泳道、翻周、非本周显示、所有作业状态和导航入口。
- 必要回归与独立 Android 实跑；无需无关全库测试。

## 设计与实施

- [x] 课表：周导航重新排版，周视图与当日清单可切换；当日清单保留重叠课程、晚课和非本周规则，课程详情改为黄底时间带与明确编辑/删除/关闭操作。空态提供多种现有导入入口。
- [x] 日历：月份与返回今天独立操作，月度统计与所选日期任务分层；日期网格和下方按时间排列的作业详情入口统一；不改变事件集合和状态。
- [x] 账号：顶部连接概况、失效状态与同步动作，下方开放平台列表；平台详情弹窗组织登录、重登、退出和账号标识，保留原回调及教务退出确认。
- [x] 设置：主题预览入口做首要区域，偏好与数据/支持分区；详情有当前状态概述，开放式设置行，减少层层卡框；备份、历史归档、隐藏、作息、通知、后台、更新入口完整保留。
- [x] 课程编辑重排表单与固定保存栏；共用模态标题、边界、主次操作延续第三套，其他主题保持形状。
- [x] 先写必要行为回归并看失败：当日列表包含重叠与16节课程、详情回调可达、日历/账号新入口不写数据、设置五类导航与取消保持旧记录。已有主题/编辑/导入回归作为兼容门禁。
- [x] 受影响源码分析、变更边界核对、Android 覆盖安装；真实数据样本为独立模拟器合成数据。查看有课程、空态、日期任务、账号、设置详情与弹窗，以及其他主题代表。截图预览交付，记录未测范围。
