# 作业通 (Homework Radar)

下载：[GitHub 发行版](https://github.com/zaibuchihuoji/homework_radar/releases) · [Gitee 国内下载](https://gitee.com/zaibuchihuoji/homework_radar/releases)。请选择匹配设备架构的 APK，直接覆盖安装即可。

一个 Flutter 双端 App：汇总 **学习通（超星）** 和 **中国大学MOOC（icourse163）** 的作业/测验列表与截止时间，并在截止前推送本地提醒。取名「作业通」，如小灵通——接收作业、提醒及时。

## 功能

- **账号绑定**：App 内嵌 WebView 打开平台真实登录页（支持密码/扫码/验证码，因为是官方页面），登录后自动捕获 Cookie 存到本机。
- **作业汇总**：只显示**本学期**的作业（秋学期 8月~次年1月，春学期 2~7月，按截止时间判断），按紧急度排序；列表**左滑可隐藏**单条作业（老师撤回、不需提交的场景），隐藏后不再提醒，可在「设置 → 已隐藏的作业」中恢复。
- **桌面小组件（Android）**：两套——「最近截止」作业组件（内容随尺寸自适应、列表可滚动）
  和「今日课表」组件（当天课程按节显示，进行中的课随主题高亮，每 30 分钟自动刷新状态）。
- **截止提醒**：截止前 24h / 6h / 1h 本地通知（设置里可开关）；每次同步时会重新预约全部未来提醒。
- **上课提醒**：课前 15 分钟（可在设置里关）；支持**按学校自定义作息时间**（设置 → 作息时间），
  提醒与课表时间轴即时生效；一次排满未来 8 周并自动封顶；同一时段多门课（选修冲突）各自提醒。
- **教务课表（超级课程表式导入）**：「课表」Tab 周视图，支持**任意学校**：首次使用手输
  学校教务系统网址（金智青果 / 正方 / 强智 / URP 等常见教务系统均可），在 WebView 里登录、
  打开课表页后自动检测表格并解析，解析结果先进**预览页**逐条确认/修正（星期、节次、教师、教室）
  再入库，与作业截止一起看；支持周次切换/校准、课前 15 分钟提醒（设置里可开关）。
  教务平台通常仅校园网/VPN 可达。解析失败时有两条兑底路：右上角菜单「粘贴文本导入」「截图导入」
  （离线 OCR，安装包约增大 15MB）。抓取页长按「课表」标题可复制原始页面，便于排查解析问题。
  同一学期重新导入时，预览页人工修正过的课程会优先保留，不被新抓取结果覆盖。
- **课表日常使用（超级课程表式体验）**：周视图**左右滑动切周**，顶部显示月份，翻到别的周时
  **非本周课程淡化显示**（可在菜单里关），重叠课程自动**并排分列**，另有「回到本周」浮钮。
  课程支持**手动添加**（右上角 +，选修课/体育课等教务里没有的课）、点开详情后**编辑/删除**
  （人工修正值重抓时优先保留，手动课程不会被重抓清掉；教务导入的课删除后重新抓取会回来）、
  **长按换颜色**（按课程名生效）。
- **数据备份**：设置 → 备份，导出/导入 JSON（课表、作业（含手动添加与备注）、学期校准、作息、隐藏作业、偏好）；
  换机/重装不再丢数据。备份文件**不含账号 Cookie**。
- **调试日志**：长按设置页「上次同步」查看全部原始请求/响应，平台改版时方便定位。

- **后台同步（Android）**：默认每 30 分钟检查，可在「设置 → 后台同步」中调整为 15 / 30 / 60 / 120 分钟或关闭。临时失败自动重试，登录过期时提示重新登录；同步结果同时更新 App、桌面小组件与提醒。具体执行时间由 Android 根据网络和省电状态安排。
- **App 内更新（Android）**：优先从 Gitee 检查和下载安装包，失败时自动回退 GitHub；切换来源仍锁定同一版本和架构。弹窗和通知栏显示进度，收起后继续后台下载；下载完成并校验后点击安装，保留已有数据。按设备架构选择安装包，也兼容旧通用包。

## 构建

```bash
# 需要本机有 Flutter SDK + Android SDK（详见仓库根目录 env.sh）
flutter pub get
flutter build apk --debug
flutter build apk --release --split-per-abi  # 分别生成 ARM64 / ARM32 / x86_64 安装包
flutter run                    # 直接跑
```

iOS 端代码就绪（WebView 登录、Cookie 通道、通知均已适配），需要 macOS + Xcode 编译：
`flutter build ios`。

## 使用说明

1. 「账号」页 → 选择平台 → 在 WebView 中完成登录 → 自动返回并同步；
2. 「课表」页首次使用 → 输入学校教务网址 → 登录并进入课表页 → 自动抓取 → 预览确认入库；
   换学校用右上角菜单「更换教务平台」，教务打不开/解析不了时用「粘贴文本导入」或「截图导入」；
3. 「作业」页查看所有作业，下拉刷新；
4. 「设置」页配置提醒时间与查看调试日志。

## 技术要点 / 免责

- 两平台均无官方开放 API，本应用实现方式：
  - **学习通**：`visit/courses/list` 课程列表 → 课程页隐藏域取 `courseId/clazzId/enc` → `work/getAllWork` 作业列表（HTML 解析）；
  - **MOOC**：Cookie + `csrfKey`，`learnerCourseRpcBean.getMyLearnedCoursePanelList.rpc` 课程列表，`CourseBean.getMocTermDto`（DWR）抽取测验/作业。
  - **教务课表**：WebView 加载用户配置的教务网址，检测到含「星期一~日」表头的表格后提取 HTML，
    由通用网格解析器（`timetable_parser.dart`）解析，兼容金智青果/正方/强智/URP 的常见格子写法；
    兑底的文本解析与 OCR 布局重建（`timetable_text_parser.dart` / `timetable_ocr.dart`，ML Kit 离线中文模型）
    与教务抓取共用同一套单元格解析内核。
- 所有请求做了域白名单校验（仅 `*.chaoxing.com` / `*.icourse163.org`），两路并发、单路请求间隔 ≥0.7s，避免触发风控。
- 账号 Cookie 等敏感凭据经原生安全存储加密落盘：Android 用 Keystore AES-GCM，iOS 用 Keychain；
  老版本的明文数据在启动时自动迁移。
- 两个桌面小组件共用 `HomeWidget` 数据通道：Dart 侧把结构化 JSON 写进 `HomeWidgetPreferences`，
  原生 RemoteViews 渲染；作业组件的列表由 RemoteViewsService 滚动加载，课表组件
  推送整周数据，头部日期与「今天取哪天」由原生在每次重绘时按当前时间判定——
  系统 30 分钟重绘一次，跨天时不用打开 App 也能自动换到新的一天。
- 只读取自己账号的只读数据，不代做、不自动提交、不签到。
- 接口无官方文档，平台改版可能导致解析失败；此时打开「设置 → 接口调试日志」把响应内容反馈出来即可快速修复。

## 已知限制

- 正方 / 强智 / URP 的解析器按公开常见格式编写（单测覆盖），尚未在真实页面逐一验证；
  首次遇到陌生格式时抓取可能失败，此时用文本/截图导入兑底，并把原始页反馈出来以便适配；
- OCR 重建依赖截图里「星期一~星期日」表头完整、文字清晰；无表头时全部课程需在预览页手动指定星期；
- MOOC 的作业截止时间依赖课程结构接口里的字段，部分课程可能显示「截止时间未知」；
- iOS 端因开发机为 Windows，未实际编译验证；
- 学习通部分学校的定制页面可能字段略有差异。
